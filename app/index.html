ポチレシピ

動画の概要欄からレシピと買い物リストを作る Android アプリ

ポチレシピは、レシピ動画の材料と作り方を、文字のレシピにして保存するアプリです。

YouTube の動画の URL を貼ると、概要欄に書かれた材料・分量・作り方を読み取ります。分量を確かめるたびに動画を開き直したり、スクリーンショットを探したりしなくて済みます。

材料表から足りないものを選べば、そのまま買い物リストになります。

Google Play で入手

できること

  • 概要欄を読み取る：動画の URL を貼ると、材料・分量・作り方を取り出します。読み取れなかった行は、その場で直せます。レシピサイトの URL や、文章の貼り付けからも読み取れます。
  • 買い物リストにする：材料表から足りないものだけを選ぶと、買い物リストになります。複数のレシピの同じ材料はひとつにまとまり、売り場の順に並びます。
  • 人数を変える：人数を変えると分量を計算しなおし、その量で買い物リストに入ります。
  • 探す：料理名だけでなく、材料・調理時間・料理家でも絞り込めます。
  • 献立を決める：カレンダーにレシピを入れておくと、その期間の分をまとめて買い物リストにできます。
  • 作った記録を残す：作った日・写真・気づいたことのメモを残せます。メモは、次にそのレシピを開いたときに目に入る場所に出ます。

広告はありません。無料プランでもすべての機能を使えます(保存できるレシピは 30 件まで)。

Google ドライブとの同期と、Google のデータの使い方

スマートフォンとタブレットなど、複数の端末で同じレシピや記録を使えるようにする同期の機能があります(対応するバージョンから使えます)。同期は任意で、オンにしなければ Google アカウントは使いません。

  • 何のために使うか：あなたのレシピ・メモ・調理の記録・写真・買い物リスト・献立を、あなた自身の Google ドライブに保存し、あなたのほかの端末と同じ内容に保つためだけに使います。
  • 求める許可：「Google ドライブ内の、このアプリ自身の設定データの表示と管理」(drive.appdata)だけです。ドライブにあるほかのファイルは、見ることも変えることもできません。
  • 開発者は受け取りません：データは端末から Google ドライブへ直接送られます。開発者はサーバーを運用しておらず、内容を見ることはできません。
  • やめ方・消し方：アプリの設定からいつでも同期をオフにでき、ドライブに保存したデータを消すこともできます。

くわしくはプライバシーポリシーをご覧ください。

YouTube API サービスの利用について

このアプリは、動画の情報を取得するために YouTube API サービスを使用しています。ご利用にあたっては YouTube 利用規約および Google プライバシーポリシーが適用されます。
