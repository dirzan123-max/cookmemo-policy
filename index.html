プライバシーポリシー

最終更新日: 2026年11月17日

「ポチレシピ」（旧名「リピレシピ」。以下「本アプリ」）は、Tsunkuota（以下「開発者」）が提供するAndroidアプリです。本ポリシーは、本アプリの利用にあたって取り扱う情報について説明します。

1. 本アプリが収集する情報

開発者は、氏名・メールアドレス・アカウント情報などの個人情報を収集しません。本アプリ独自のユーザー登録はありません。開発者はサーバーを運用しておらず、ユーザーのデータを受け取ることはありません。

本アプリが端末内に保存する情報は以下のとおりです。後述の「Googleドライブとの同期」をユーザーがオンにした場合を除き、いずれもユーザーの端末内にのみ保存されます。

  • 保存したレシピ（動画のタイトル・URL・概要欄の本文、材料、作り方、作り手やチャンネルの名前）
  • 自分で書いたメモと、作った日時・所要時間・感想などの調理の記録
  • 調理の記録に添えた写真
  • 買い物リストの内容
  • 献立(カレンダーに入れたレシピと、献立のパターン)
  • アプリの設定（表示テーマ、既定の人数、通知の設定など）

これらのデータは、後述のGoogleドライブとの同期・Androidの端末バックアップ機能と、ユーザー自身が共有操作を行った場合を除き、端末の外へ送られることはありません。いずれの場合も、開発者がデータを受け取ることはありません。

2. 通信を行う場面

本アプリは、次の場面でのみ外部と通信します。それ以外の動作はすべて端末内で完結します。

  • YouTubeの動画からレシピを取り込むとき：入力された動画のURLからYouTube Data API v3へ問い合わせ、タイトル・概要欄・サムネイル・再生時間を取得します。送信されるのは動画の識別子であり、ユーザーを識別する情報は含みません。
  • 保存済みレシピの情報を更新するとき：取り込みから一定期間が過ぎたレシピについて、同じ方法で情報を取り直します。
  • アプリ内で動画を再生するとき：YouTubeの埋め込みプレーヤーを表示します。この再生はYouTubeによって提供されるものであり、YouTubeが独自にCookie等を利用する場合があります。
  • レシピサイトのURLから取り込むとき：入力されたページを読み込み、材料や作り方を取り出します。
  • レシピの画像を表示するとき：動画やレシピページのサムネイル画像を、その画像のURL（YouTubeの画像サーバーやレシピサイト）から読み込み、端末内に一時保存して表示します。送信されるのは画像の取得要求のみで、ユーザーを識別する情報は含みません。
  • 「要望・不具合を送る」「うまく読み取れないことを報告する」を選んだとき：外部のフォーム（Googleフォーム）をブラウザで開きます。読み取りの報告では、その動画やページのURL・チャンネル名・アプリのバージョンと、読み取りに使った文章（概要欄や貼り付けた文章）の先頭1500字までをあらかじめ入力した状態で開きます。送信するかどうか、何を書くかはユーザーが決められ、送信先はGoogleフォームです。フォームはメールアドレスを収集しません。
  • Googleドライブとの同期をオンにしているとき：ユーザーが選んだGoogleアカウントのGoogleドライブと通信し、同期のデータを保存・取得します。くわしくは「5. Googleドライブとの同期（任意）」をご覧ください。

本アプリは広告を表示しません。利用状況の解析（アクセス解析）やクラッシュ情報の収集も行っていません。

3. YouTube API サービスの利用について

本アプリは、動画の情報を取得するためにYouTube API サービスを利用しています。本アプリを利用することで、ユーザーはYouTubeの利用規約に同意したものとみなされます。

Googleによる情報の取り扱いについては、Googleプライバシーポリシーをご参照ください。

動画の取り込みにGoogleアカウントへのログインは必要ありません。本アプリは、ユーザーのYouTubeアカウントの情報（登録チャンネル、再生履歴など）にはアクセスしません。Googleアカウントに紐づくアプリの権限はGoogleのセキュリティ設定ページから確認できます。

4. 端末の権限について

  • 通知：キッチンタイマーが終わったことを知らせるために使います。すべて端末内で処理されるローカル通知で、外部への送信は行いません。
  • カメラ・写真：作った料理の写真を記録に添えるときに、ユーザーが選んだ場合にのみ使います。撮影・選択した写真はアプリ内の領域に保存され、外部には送信されません。ユーザーが明示的に操作した場合のみ、端末のギャラリーへ保存します。
  • アラーム・常駐（フォアグラウンドサービス）：調理中にアプリを離れてもキッチンタイマーが動き続けるようにするために使います。

5. Googleドライブとの同期（任意）

本アプリには、複数の端末で同じデータを使えるようにする同期の機能があります（対応するバージョンのアプリで利用できます）。同期は任意で、ユーザーが設定画面でオンにしたときだけ働きます。オンにしなければ、本アプリがGoogleアカウントを使うことはありません。

  • 保存されるもの：レシピ、メモ、調理の記録、記録に添えた写真、買い物リスト、献立、アプリの設定の一部、端末の名前（同期している端末の一覧を表示するため）。
  • 保存される場所：ユーザーが選んだGoogleアカウントのGoogleドライブにある、本アプリ専用の領域（アプリデータフォルダ）です。データは端末からGoogleドライブへ直接送られます。開発者はこのデータを受け取らず、内容を見ることもできません。
  • 求める許可：「Googleドライブ内の、このアプリ自身の設定データの表示と管理」（drive.appdata）のみです。本アプリは、ユーザーのGoogleドライブにあるほかのファイルを見ることも、変更することもできません。
  • Googleアカウントの情報：同期に使うアカウントのメールアドレスを、設定画面での表示と、同じアカウントで同期していることの確認のために端末内に保存します。開発者には送信されません。
  • 利用目的：ユーザーのデータをユーザー自身の端末のあいだで同じ内容に保つことだけに使います。広告、解析、第三者への提供には使いません。
  • やめ方・消し方：設定画面の「Googleドライブで同期」から、同期をオフにできます（端末のデータもドライブのデータも残ります）。同じ画面の「ドライブのデータを消す」で、Googleドライブに保存した同期のデータをすべて削除し、Googleドライブへの許可を取り消せます。Googleドライブの設定の「アプリの管理」から本アプリのデータを削除することや、Googleアカウントの「サードパーティ製のアプリとサービス」から許可を取り消すこともできます。

Googleドライブに保存されたデータの取り扱いには、Googleプライバシーポリシーが適用されます。

本アプリによる、Google APIから受け取った情報の使用および他のアプリへの転送は、限定的な使用に関する要件を含め、Google API サービスのユーザーデータに関するポリシーに準拠します。

6. 端末変更時のデータ引き継ぎについて

開発者が管理するサーバーへのバックアップは行っていません。Googleドライブとの同期を使わない場合、データの引き継ぎは次の2つの方法によります。

  • 引継ぎファイル：設定画面の「データ」からファイルを書き出し、新しい端末で読み込む方法です。ファイルの保存先と受け渡し方法はユーザーが決めます。
  • Android標準の自動バックアップ：同じGoogleアカウントで新しい端末にログインした際に、Googleが管理するクラウドストレージへ暗号化された状態でバックアップ・復元される仕組みです。本アプリではレシピなどのデータベースのみが対象で、写真は含みません。詳細はAndroidのバックアップに関するGoogleのポリシーをご参照ください。

7. データの削除

以下のいずれかの方法で、本アプリが端末に保存したデータを削除できます。

  • レシピごとに削除する（削除から30日以内であれば、設定画面の「ゴミ箱」から戻せます）
  • 買い物リストの「全部消す」で、リストの内容を消す
  • 端末のアプリ設定から「ストレージを消去」またはアプリのアンインストールを行う（写真を含む、端末内のすべてのデータが削除されます）
  • Googleドライブとの同期を使っている場合は、設定画面の「ドライブのデータを消す」で、Googleドライブに保存した同期のデータを削除する

8. 対象年齢・お子様のプライバシーについて

本アプリは特定の年齢層を対象としたものではありません。開発者は、本アプリを通じて13歳未満のお子様から意図的に個人情報を収集することはありません。

9. プライバシーポリシーの変更

本ポリシーの内容は、本アプリの機能追加・変更に伴い予告なく改定される場合があります。重要な変更がある場合は、本ページの「最終更新日」を更新してお知らせします。
